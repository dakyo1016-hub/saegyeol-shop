# 새결 프로젝트 이력

이 문서는 다른 컴퓨터나 새 작업 세션에서 프로젝트의 방향과 구현 범위를 빠르게 파악하기 위한 인수인계 메모입니다.

## 제품 방향

새결은 무신사·에이블리·29CM의 탐색 경험을 참고하되, 패션과 뷰티를 취향의 결이라는 하나의 언어로 묶은 큐레이션 커머스입니다. 시각적으로는 큰 타이포그래피, 에디토리얼 이미지, 여백 중심의 레이아웃을 사용합니다.

## 구현된 주요 흐름

1. 브랜드와 메인 화면
   - `새결 · 새로운 취향의 결` 브랜드 체계
   - 인터랙티브 히어로와 광고 배너 슬라이드
   - 네이밍 틴트 및 패션 캠페인 배너

2. 상품 탐색
   - 신상품, 랭킹, 패션, 뷰티, 세일 카테고리
   - 상품 수 확장과 착용·제품 디테일 이미지 구성
   - 고객 행동을 로컬 데이터로 반영하는 추천 순서

3. 상품 상세
   - 옵션 선택 후 장바구니 담기
   - 의류 실측표와 뷰티 톤 정보
   - 사진 리뷰 우선 노출, 체형 유사 리뷰 정렬, Q&A
   - 페이지 하단 연관 상품 슬라이드

4. 고객 기능
   - 찜 보관함과 장면 보관함
   - 쿠폰 적용 예상 결제 금액
   - 배송 정보, 체형 정보, 문의 내역을 포함한 마이페이지
   - Google 로그인과 Supabase 세션 연동
   - 카카오 우편번호 검색 및 지도 표시

5. 결제와 운영
   - Toss Payments 테스트 결제 준비·승인 API
   - 상품 등록·수정이 가능한 관리자 화면
   - 매거진 페이지와 에디토리얼 콘텐츠

6. 접근성과 확장
   - 모바일 하단 내비게이션
   - 사용자 선택형 다크 모드
   - Groq 기반 AI 쇼핑 가이드 `결이`

## 외부 서비스 설정 체크리스트

- Supabase: Google Provider, Site URL, Redirect URL, 허용 도메인
- Google Cloud: OAuth 승인 화면과 승인된 리디렉션 URI
- Kakao Developers: JavaScript SDK 도메인과 플랫폼 키
- Toss Payments: 테스트 클라이언트/시크릿 키와 결제 승인 서버 환경변수
- Groq: 서버 전용 API 키

비밀키는 저장소에 넣지 않고 배포 환경 또는 로컬 `.env.local`에서 관리합니다.
